# Substitutions for banned words

These are banned words that have caused friction in ov, merged into ai 15 September 2026. Use the left column, never the right. Plural, past-tense and gerund forms of the words in the right column are also banned, and should be substituted using the same form.

The rules that apply to all projects are in `memory/shared/truth/conventions.md`, which also explains the **same** column.

| Use               | hooked | same | Never            | Meaning                                     |
| ----------------- | ------ | ---- | ---------------- | ------------------------------------------- |
| string, csv       |        |      | joined line      | several values run together as one piece of text |
| drawing in a guide|        |      | block of drawing | a picture made of characters, inside a file |
| renderer          |        |      | drawer           | the component that turns a file's text into the html, ai's Edit_Markdown |
