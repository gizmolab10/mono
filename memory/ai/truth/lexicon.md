# ai lexicon

The words used in this project. When writing prose, comments, log lines, or test names, use these words exactly, even when near synonyms exist. If it's here, that's its name. Reaching for a word that is not here, say so and stop — do not invent one.

ai's page is kb's, so kb's [lexicon](../../kb/truth/lexicon.md) applies here whole, and the shared [banned words](../../shared/truth/conventions.md) list with it. This file holds ai's own words alone. ov's lexicon, 31 entries, was merged here 15 September 2026: every entry is already kb's, so none is repeated.

- **project** — essentially the same as a collection
- **renderer** — Edit_Markdown.svelte, the component that turns a file's text into the html and draws it as the operation view. Never drawer, a part of a cabinet to Jonathan. Decided 15 September 2026.
- **composing labels** — labels_for, ai's since step 12 of the plan: the labels an unlabeled file is given when first opened for editing, read off its own words. The first heading is the title, the first sentence the brief, today the date, kind_when_new the kind, tag_when_new and stale the tags. Decided 14 September 2026.
