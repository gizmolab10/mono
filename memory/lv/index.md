# lv

Tommy's Vineyard Space — a place to share the work and fun of owning a vineyard, representing it with descriptions and photos. Svelte site, deployed on Netlify. Structure emerges as needed; don't over-organize early.

**Current state:** lv adopts core — the sizes, the colors, the hits manager, the hamburger and the section, all through `common/Core.ts`, with lv's own switches beside it in `Customizations.ts`. Every code file under `src` is capitalized, each word after an underscore too. The sidebar is off by default and its remembered value counts for nothing while it is; the shell has a top row that is core's `Section`, holding nothing yet. Confirmed on screen 1 September 2026. the pictures-and-captions truth stands current; the old-notes code debt leads `zone/ideas.md`, its done section left to git; the map lives in `truth/`. Open: which remote hosted storage, if the pictures outgrow the repo.

Its whole code was copied on 1 September 2026 into [gallery](../gallery/index.md), which will become something else.
