# Scope

In: browsing and editing the repo's markdown files; tags, kinds, and labels — they are the app's own subject; a single source for every size and color.

Out (deliberately): documents, storage, and chat — those are ji's, and belong nowhere here.

The fuller statement lives in [ov - goals](../../../ov/notes/guides/design/ov%20-%20goals.md).
