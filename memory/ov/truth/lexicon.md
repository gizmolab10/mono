# ov lexicon

ov already keeps its terms in [ov/notes/guides/pre-flight/lexicon.md](../../../ov/notes/guides/pre-flight/lexicon.md) — that file remains the single source until a settle decides whether to move it here. Read it as this project's lexicon; add no term in both places.

Coined here on 28 August 2026, since the old file predates them:

- **clickable** — the pill button standing on a separator line that folds the section below it away, and says what it hides while folded.
  Not: any other button; not a word in the file's contents.
- **information rows** — the rows of the editor's label form holding title, date, brief and use when.
  Not: the kinds row, the tag rows.
