# mu

**Current state:** memory/mu and mono/mu are both up — mono/mu is ov's structure with one App.svelte on port 5186, in the hub under U, in the servers script, a collection in ov's browse. mu is a music browser: scan the disk, read each file's own labels, offer several hierarchies over one collection. The zone holds the goal, the challenges, and what is settled. Since 7 September 2026 it adopts core and draws panel: App.svelte holds the `.app` div and the width arithmetic, Controls a row with core's hamburger and the project's name centered on it, Details an empty column, Operation the content box with one line in it. Everything it takes from core arrives through `common/Core.ts`, the only file that reaches through the `core` alias. `Customizations.ts` waits, empty, for the first switch that is mu's alone. No flesh yet: the goal in zone/project goal.md says what goes in each region.
