# UX terms and concepts

## separator

- thickness
- option to add a title
- option for clickable -- all along the sep
- fold -> reduce content to minimal
## section and subsection

- assumes above and below -> a separator or edge of view
- equal top and bottom padding around content

## stack of sections and views


| kind       | separator | foldable  |
| ---------- | --------- | --------- |
| top        | -         | -         |
| section    | huge      | often     |
| subsection | normal    | sometimes |
