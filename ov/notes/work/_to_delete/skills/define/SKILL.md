# define

Write skill — every run logs.

Read `memory/shared/truth/protocol.md`, section "Prose and terminology", and execute the coining or redefinition procedure exactly. The file is the procedure; do not run it from recollection. The lexicon has no other door: no synonyms, no silent redefinition, and plain language instead of coining when the term would not otherwise recur.

Report what was written — the entry and its `D:` line — and, on redefinition, every old-sense use that was reworded.
