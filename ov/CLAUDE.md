# CLAUDE

> a browser and editor for every markdown file in this repo: a list on the left, one file's words on the right, and every size and color coming from one place.

Ported from ji. What belongs here — and what deliberately does not — is [ov - goals](../memory/ai/truth/design/ov%20-%20goals.md).

Read `memory/ai/truth/lexicon.md` at session start. It names everything in this project: use those words in prose, comments, log lines and test names, and invent no synonyms.

The file map is `memory/ov/truth/map of ov files.md`. Read it instead of discovering files using regex and wildcards, and update it when files are added, moved, or removed.

Tags, kinds and labels are the app's own vernacular.

Past mistakes never to repeat, this project's own, are in `memory/ov/logs/learn.md`, made the day the first one is written. Those that apply everywhere are in `memory/shared/logs/learn.md`.
