# Hub

- [dispatcher.py](dispatcher.py) — the dispatcher: the small server that reads and writes files on this machine, and the db, for the overview app and the hub page. Its routes are proved by [test_dispatcher.py](test_dispatcher.py), asked of the running dispatcher.
- [database.py](database.py) — the db: `ov.db` beside it, git-ignored, holding files, labels, sources and rules. Only the dispatcher reads and writes it. The dispatcher's `/scan` fills it from every file's own block, `/all-labels` hands it all back, `/set-fields` writes a file's title, description, use_when and date, and `/strip-block`, asked with a confirm word, takes the whole block off every file the db holds. `/sources` and `/set-sources` read and make a file's authors and where it came from. `/rules`, `/add-rule` and `/remove-rule` list and change the rules that give a file its kind and tags from its name, location or content, run on every file changed or new at each look. A thread started at launch looks at the disk every 3 seconds and `/rescan` does so on request: a file changed, moved or gone in the Finder is noticed and its row brought into line, labels kept. `/dump` writes every table as plain text to `ov.sql` beside the db, which enters git though the db never does, and `/restore`, given a .db name, makes that file beside the db from the dump, never the live db, so the labels come back from either the saved file or the dump. Proved by [test_database.py](test_database.py) against a db of its own, with no dispatcher running.
- [index.html](index.html) — the hub page.
- [ports.json](ports.json) — every server's port, the one place.
- [ov.sql](ov.sql) — the dump, every table of `ov.db` as plain text, written by `/dump` and read back by `/restore`. It enters git, the db never does. `ov.db.before-step-2` beside it is the db saved before step 2 of the plan, git-ignored like every db file here.
- [servers.sh](servers.sh) — start, restart, kill or verify the dev servers, each named in ports.json, one by name or all. The dispatcher runs it for the hub page's restart button.
- [start-hub.sh](start-hub.sh) — kill whatever holds the hub's and the dispatcher's ports, then start both: the hub page served from this folder, and the dispatcher. Nothing calls it, it is run by hand.
- clean.worktrees.sh — clearing worktrees. In [tools/scripts](../scripts/clean.worktrees.sh) today, moving back here.
