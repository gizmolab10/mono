# Tools

Scripts and utilities for development workflow.

## Contents

- [Scripts](./scripts/)
- [finished.py](finished.py) — writes memory/shared/zone/finished.md, one line per memory file holding finished work; the shorthand `finished` runs it. [test_finished.py](test_finished.py) proves it on a made-up project folder.
- [process_finished.py](process_finished.py) — moves one project's finished work into its work journal and its done folders' files into its logs folder; the shorthand `process finished <X>` runs it. [test_process_finished.py](test_process_finished.py) proves it.
